Shouku Launcher is a free desktop app that puts every Shouku game in one place. Browse the games, read about them, watch them in action, and install, update and play them with one button, without visiting each game's page.

Download the launcher

How it works

  1. Install the launcher for your computer (see below).
  2. Browse the Store. Every game has its title, full description, screenshots and a 20-second gameplay video, plus its version, age range and what it teaches.
  3. Press Install. The launcher downloads the game straight from shoukugames.org and installs it for you. You can watch the progress on the Downloads tab.
  4. Press Play. Your installed games are in the Library, which also keeps track of how long you have played each one.
  5. Stay up to date. Each time the launcher starts (or when you press the refresh button), it checks shoukugames.org for new games and new versions. When a game has an update, its button changes to Update, and new games appear in the Store by themselves.
  6. Tell us about problems. The Bug report tab helps you write a clear report and send it to us on GitHub or by email.

Windows and Linux versions

There are two versions of the launcher, and each one only offers games made for its own system. That way you never download a file your computer can't run.

The Windows launcher never lists or downloads Linux packages, and the Linux launcher never lists or downloads Windows programs.

Installing on Windows

  1. Download ShoukuLauncher-Setup-1.1.0.msi above and double-click it. It uses Windows' own installer, installs just for you, and doesn't need an administrator password.
  2. If Windows says "Windows protected your PC", click More info and then Run anyway. This can appear because the installer isn't code-signed yet.
  3. Shouku Launcher is then in your Start menu and on your desktop. To remove it, use Settings → Apps.

Prefer not to install anything? Download the portable ZIP instead, right-click it and choose Extract All, then open Shouku Launcher.exe in the extracted folder.

Installing on Debian or Ubuntu

Download the .deb file above, then double-click it to open it in your software centre, or install it from a terminal in the folder where you saved it:

sudo apt install ./shouku-launcher_1.0.0_amd64.deb

Shouku Launcher is then in your applications menu. When you install a game, the launcher asks for your password so it can install the game's .deb package.
